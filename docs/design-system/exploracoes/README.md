# Explorações de cores

Arquivos históricos da escolha do destaque visual em 30/10/2026:

- `azul-e-cobre.html`: estudo inicial de azul e cobre.
- `prazo-certo-cobre-aplicado.html`: primeira aplicação em uma tela demonstrativa.
- `prazo-certo-champanhe.html`: alternativa aprovada pelo usuário.

São fragmentos de prévia criados para o visualizador do Codex, não páginas autônomas da aplicação. Alguns controles opcionais dependem do host do visualizador.
O padrão vigente está no guia `../README.md` e nos tokens de `styles/tokens.css`. A aplicação do champanhe já foi integrada à `main` pelo PR #2.
